# Flutter IPTV Player

A Flutter mobile IPTV player that lets users load the channel list, and plays streams inside the app.

> ⚠️ Disclaimer: This app does **not** provide or host any video content.  
> The sample playlists mentioned below come from **iptv-org/iptv**. [1](https://github.com/iptv-org/iptv)[3](https://deepwiki.com/iptv-org/iptv/5-user-guide)
> Requires internet Connection
---

## ✨ Features

- ✅ Fetch & parse playlist into channels
- ✅ Channel list with logo
- ✅ Grouping by category
- ✅ Search channels
- ✅ Favorites
- ✅ Fullscreen streaming player

---

## 🧰 Tech Stack

- Flutter (Dart)
- Network: `http` (or `dio`)
- Playlist parsing: simple M3U parser

---


## 🛠️ Getting Started

### Prerequisites
- Flutter SDK - installed
- Android Studio / VS Code
- Android device/emulator (and/or iOS device/simulator)

### Clone & Install
```bash
git clone https://github.com/JS-Coder007/live_tv_app.git
cd live_tv_app
flutter pub get
``
